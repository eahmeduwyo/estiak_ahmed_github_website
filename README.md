Open index.html to view the website. For publishing, upload index.html, styles.css, script.js, .nojekyll, and the assets folder to your web host or GitHub Pages repository root.

The supplied JavaScript is preserved unchanged, including mobile navigation, saved light/dark preference, project filters, scroll reveals, copy email, and automatic footer year. Clipboard copying works on HTTPS or localhost; the original email fallback remains available elsewhere.

Content was updated from the current CV. The CV and all CV links are excluded. Both contact email addresses are retained. The two requested photographs are included, with display cropping controlled by CSS.

## Updating an existing GitHub Pages site
Replace index.html, styles.css, script.js, and the assets folder together at the repository root. Do not upload the ZIP itself as the website. The stylesheet URL includes a version query so browsers request this update instead of reusing an older stylesheet. Wait for the GitHub Pages deployment to finish, then reload.

Portrait: capped at 240 pixels on desktop/tablet and 220 pixels on phones, shrinking further if needed. Conference image: capped at 360 pixels, or 300 pixels on phones, with its full 4:3 frame visible. Tablet navigation collapses at 1024 pixels. Existing colors, typography, sections, and JavaScript features are retained.
